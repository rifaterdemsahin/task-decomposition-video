Recommendations

  1. Grow the VM disk to 40 GB or more

    94% used now. Model downloads, renders and a second voice will fail at this level.

  2. Make the images on the Mac

    Run tools/gen_images.py with the same JSON there, commit the PNGs, then rerun ./build.sh here.

  3. Add a live Claude demo

    A 30–60 s screen recording of the five-step chain on real data would meet "show it working" better than diagrams alone.

  4. Reveal diagrams step by step

    Split the After and Chain diagrams into staged SVGs, as the recap already does, so each node appears as it is spoken.

  5. Store videos outside plain git

    Use Git LFS or a GitHub release asset once there are several versions of the MP4.

  6. Set git identity once

    git config --global user.name and user.email on this VM.
