Skool Course Video Creator

A reusable skill that turns a topic brief into a ~5 minute narrated Skool lesson and its lesson site, with local tools only. This lesson was built with it.

What one run produces

🎬 Lesson video1080p, Kokoro voice, hook, chapters, recap, animated assignment
💬 Captionssmall, burned in, word-by-word fill; SRT and VTT too
🧭 UML + emojiclass, activity and sequence diagrams with colour emoji
🌐 Lesson siteGitHub Pages with a shared menu, board, effort report, live tests

Start a new lesson

bash .claude/skills/skool-course-video-creator/scripts/new_lesson.sh prompt-chaining "Prompt Chaining" ../prompt-chaining-video

Run inside this repo. It copies the toolchain, renames the slug everywhere, starts video/<slug>.json from the lesson template, and runs git init. Then ask Claude Code to use the skill with your topic brief.
