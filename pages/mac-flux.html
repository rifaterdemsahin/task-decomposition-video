Background images · FLUX.2 Klein 4B · Apple Silicon

Make the lesson's images on your Mac

The Linux build VM has no GPU, so the backgrounds there are drawn on the CPU. Run this once on an Apple Silicon Mac to replace them with FLUX images; the next build keeps them.

Paste this in Terminal

curl -fsSL https://raw.githubusercontent.com/rifaterdemsahin/task-decomposition-video/main/tools/mac_flux.sh | bash

Read the script first: tools/mac_flux.sh. Set DIR=… before bash to clone somewhere other than ~/task-decomposition-video.

What it does

  1. 📥 Clones the repo, or pulls it if it is already there.
  2. 🎨 Installs mflux with uv if it is missing.
  3. 🦙 Starts Ollama if needed and pulls gemma3:12b, which writes one image prompt per scene.
  4. 🖼️ Runs tools/gen_images.py for the 8 scenes in video/images/plan.json: intro, chapter cards, two concept slides and the assignment. Diagram slides keep their full-size UML.
  5. 🚀 Commits video/images and the scene file, and pushes to main.

What it needs

🍏 Apple Silicon MacM1 or later; mflux runs on MLX, so an Intel Mac Pro will not work.
💾 About 25 GB freeFLUX.2 Klein 4B is ~15 GB, gemma3:12b ~8 GB, downloaded on first run.
🧰 uv and Ollamabrew install uv ollama
🔑 Push accessgit on the Mac must be able to push to the repo.

Then

Tell Claude the images are pushed. The Linux build pulls them, keeps them (because video/images/prompts.json now exists), re-renders the video and redeploys this site.
